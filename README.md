**Tech Stack:** Go, Kafka, Kubernetes, AWS, React
 
B2B SaaS proxy layer that sits between engineering teams and AI API providers, enforcing budget policies, rate limits, and spend visibility in real time. Built for platform and ML teams that need cost governance without changing their existing API call patterns.
 
### 📈 FinSight — SEC 10-K Q&A Chatbot
**Tech Stack:** Python, FastAPI, BM25, Dense Retrieval, Cross-Encoder
 
Hybrid RAG pipeline for querying SEC 10-K filings. Combines BM25 sparse retrieval and dense vector search with Reciprocal Rank Fusion (RRF) and a cross-encoder reranker for high-precision answers. Includes two refusal gates to handle out-of-scope and low-confidence queries.

**Tech Stack:** Scala, Apache Spark, AWS EMR, Lambda, gRPC
 
Built a distributed system with encoder-decoder architecture for parallel text processing. Designed microservices exposing inference through REST and gRPC APIs, deployed on AWS Lambda with optimized data partitioning strategies.
